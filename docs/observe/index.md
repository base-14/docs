# Observe

Use Scout's observability tools to explore traces, query logs, and visualize
metrics across your stack. Start with APM for service health, traceX for
distributed tracing, and logX for log analysis, then build dashboards to track
trends over time.

## Get Started

- [APM](../operate/apm/getting-started) - Service, operation, error,
  database, and messaging health
- [traceX](../operate/tracex) - Distributed traces end to end
- [logX](../operate/logx) - Log search and analysis
- [k8X](../operate/k8x/getting-started) - Kubernetes fleet observability
- [RUM](../operate/rum/getting-started) - How real users experience your
  mobile apps
- [pgX](../operate/pgx/quickstart) - PostgreSQL monitoring
- [Create Your First Dashboard](../guides/create-your-first-dashboard)
